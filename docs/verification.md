## 慢网抽样

在本地 HTTP 预览中，通过 Chromium CDP 模拟以下条件：

| 条件 | 设置 |
| --- | --- |
| 屏幕 | 390×844 |
| 下载 | 100,000 字节/秒（约 800 kbps） |
| 额外延迟 | 150 ms |
| 浏览器缓存 | 禁用 |
| 源站 gzip/Brotli | 未启用 |

一次冷加载样本：

| 指标 | 结果 |
| --- | --- |
| 首次内容绘制 FCP | 784 ms |
| DOMContentLoaded | 759 ms |
| 初次加载传输量（含响应头、当时已进入懒加载范围的图片） | 81,042 字节 |
| 外部站点请求 | 0 |
| 首次加载的 MP3、MP4、GIF 请求 | 0 |

这是受控的本地单次样本，不是线上速度保证，也不是旧站与新站在同一生产环境的 A/B 结果。用户向下滚动后会继续按需加载图片；播放音乐或视频后另有媒体流量。
