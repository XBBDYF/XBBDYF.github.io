# 博客重做：设计与维护

目标：让个人博客更像一个持续记录的创作空间，并改善慢速静态服务器上的首次阅读体验。

技术选择：继续使用纯 HTML、CSS 和原生 JavaScript。用 Node.js 在本地预生成文章与列表，服务器只提供静态文件，不引入运行时框架。原始 Markdown 是文章内容来源，`articles/list.json` 是列表元数据来源；修改生成 HTML 会在下次构建时被覆盖。

视觉：暖白纸色、墨绿、烧橙色，使用本地可用的中西文字体。首页以个人创作手记为主题，代码手账插画使用 CSS 与文字绘制，不下载大图。两篇最近文章作为主要卡片，其他文章以紧凑卡片呈现，旁边放作者介绍与按需音乐。移动端转单列，短文章卡片更紧凑，目录放到正文上方。项目区域使用原有小游戏的真实入口。

阅读：独立静态 URL、发布时间、预估阅读时间、静态目录、清晰的代码块、复制操作、相关推荐与邮件交流入口。保留原始文章内容，只有重复文章标题的展示形式会调整。当前不加载代码高亮库；代码块使用统一等宽排版，复制功能作为可选增强。

性能：标题、列表、正文直接输出在 HTML；没有外部字体或图标 CDN；全站仅一个样式和一个 defer 脚本。图片使用预留尺寸、WebP 缩略图与懒加载。GIF 封面使用静态首帧，GIF 正文保留；音乐在点击播放后设置 src；视频 preload 为 none。CSS/JS 带内容版本号；压缩与缓存另提供服务器参考。

兼容：保留 #home、#blog、#projects、#about、#contact 首页锚点，保留原有文章与媒体目录、旧版页面与工具。新页面资源和内部链接使用相对路径，可放在子目录。RSS 绝对地址通过 SITE_URL 设置。筛选和搜索针对标题、摘要与分类，关闭 JavaScript 后所有文章仍然显示且能进入正文。

维护约束：不依赖页面加载时的远程接口，不自动下载音乐，不用动效遮挡正文，不在页面上展示虚构的下载量或项目成绩。新增图片时可运行可选 Pillow 优化脚本；运行 Node 构建本身不需要 Pillow。发布前运行 scripts/check.cjs，确认生成内容与资源版本同步。
