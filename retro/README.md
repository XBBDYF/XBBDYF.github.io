# 复古门户版

独立入口为 `/retro/`。现代主页及其样式、脚本和构建器保持原样，两个版本共用 `articles/*.md`、`articles/list.json`、图片与音乐。

## 更新文章

先在主站文章目录写 Markdown、更新文章清单，再单独生成复古版：

```powershell
node scripts/build-retro.cjs
node scripts/check-retro.cjs
```

这两个命令不会写入现代主页。若两个版本都要更新，分别运行各自的构建命令。

继续使用仓库已有的预览：

```powershell
node scripts/serve.cjs 4173
```

访问 http://127.0.0.1:4173/retro/ 。如果预览已经运行，不需要再次启动。

## 内容与功能

- 三栏博客门户：首页、分类、月份归档与五篇现有文章的阅读页。
- 独立 RSS 订阅：`retro/feed.xml`，订阅条目链接到复古文章页。默认域名为 `https://xbbdyf.github.io/`，自定义域名或子目录部署时，构建前设置 `SITE_URL` 为主站基础地址，例如 `$env:SITE_URL = 'https://example.com/blog/'`。
- 宋体、天蓝色横幅、渐变导航、细边框栏目、小字链接、个人资料、日志日历和网页小徽章。
- 搜索匹配日志标题、摘要和分类，在浏览器内完成。
- 日历显示最新文章所在月份，带链接的日期打开当日一篇日志，同一天其他文章可在归档页查看。
- 留言入口使用邮件；网站没有公共评论数据库，也不展示虚构的评论或访客数量。
- 音乐不自动播放，展开音乐盒和选曲不下载音频，点击播放才加载。
- 关闭 JavaScript 后仍能阅读、进入分类、打开文章、使用目录；搜索、复制和内嵌音乐是可选增强。
- 缩略图与正文压缩图复用主站资源，不引入第三方 CDN 或网络字体。

## 部署与维护

将 `retro/` 一起上传到原来站点，保持上级的 `assets/`、`articles/images/`、`music/`、`old/` 和其他主站内容可访问。页面使用相对链接，也可放在网站子目录内。

修改 `retro/retro.css` 或 `retro/retro.js` 后重新运行复古版构建命令，更新资源版本。`retro/index.html`、分类、归档及 `retro/posts/` 为生成文件；内容改动应通过原始 Markdown 和构建器完成。

复古样式仅表达早期博客的视觉风格，使用的是现代语义化 HTML、响应式布局和轻量交互，并不要求旧版浏览器。
