隐私政策

应用名称：炒股人生模拟器（Stock Life Simulator）　·　生效日期：2026 年 10 月 18 日　·　版本：v1.0
一句话说明：本游戏不需要注册账号，存档只保存在你自己的设备上，不会上传；安卓版本内置「TapADN 广告 SDK」用于展示激励视频，该 SDK 会在播放广告时读取必要的设备标识（见第四节）。桌面版不含任何广告。

一、我们收集哪些信息

游戏本体不收集任何个人信息，包括但不限于：姓名、手机号、身份证号、邮箱、地理位置、通讯录、相册、麦克风、摄像头数据。

例外只有一个：安卓版本的激励视频广告由第三方广告平台提供，其 SDK 会在播放广告时读取设备信息用于广告投放与反作弊，具体范围、目的与关闭方式见第四节。桌面版与网页版不含任何广告 SDK。

二、应用申请的权限及用途

权限用途说明
网络访问（INTERNET）加载本地页面资源；安卓版本另用于向广告服务器请求广告。游戏存档不会上传。
查看网络状态（ACCESS_NETWORK_STATE）广告 SDK 用于判断网络是否可用，避免断网时反复请求广告。
安装应用（REQUEST_INSTALL_PACKAGES）仅用于广告落地页中「下载安装」类广告的跳转，不会安装任何非你主动点击的应用。

本应用不申请位置、通讯录、短信、相机、麦克风、相册、外部存储、电话状态、已安装应用列表等敏感权限（广告 SDK 自带的「读取应用列表」权限已在打包时显式移除，SDK 内的该采集开关也已关闭）。

三、游戏数据如何保存

  • 游戏存档、成就记录、音效设置保存在你的设备本地（浏览器本地存储或应用私有数据目录）。
  • 这些数据不会上传到任何服务器，也不会与任何第三方共享。
  • 卸载应用或在系统设置中清除应用数据，即会永久删除上述本地数据，我们无法恢复。
  • 单个存档文件大小约 1–2 MB，不包含任何个人身份信息。

四、第三方服务（广告）

桌面版 / 网页版：不接入任何第三方 SDK，不含广告、统计、推送、支付服务。

安卓版：接入「TapADN 广告 SDK」，由上海艾得蒽数字科技有限公司（TapTap 旗下广告平台）提供，仅用于展示激励视频广告。该 SDK 会处理以下信息：

  • 设备型号、系统版本、屏幕尺寸、语言与时区；
  • 网络类型与网络状态；
  • 应用包名与版本号；
  • 广告标识符（OAID / Android ID），用于广告归因、频次控制与反作弊。

该 SDK 不会采集你的位置、通讯录、短信、相册、IMEI、已安装应用列表，也不会读取游戏存档内容。

SDK 隐私政策：ssp.dirichlet.cn/docs/agreement；合规说明：ssp.dirichlet.cn/docs/compliance。

个性化广告开关：首次启动时会询问是否允许个性化推荐。选择关闭后广告数量不变，但相关度会降低。你也可以通过下方联系方式要求关闭。

游戏内的公司、股票、行情、新闻均为随机生成的虚构内容，不对接任何真实交易所或金融数据接口。

五、未成年人保护

本应用不主动收集用户信息，不存在专门针对未成年人收集个人信息的情形。若未成年人使用本应用，建议在监护人指导下进行；监护人可在首次启动的广告说明中选择关闭个性化广告。

六、你的权利

  • 你可以在游戏内「重新开始」清除当前存档。
  • 你可以在系统设置中清除应用数据或卸载应用，删除全部本地数据。
  • 你可以拒绝或撤回「个性化广告」授权：首次启动时可直接选择关闭；也可在系统设置中清除应用数据后重新选择。
  • 除广告 SDK 为投放广告所必需的信息外，我们本身不收集你的个人信息。

七、数据安全

由于所有数据仅保存在本地设备，数据安全取决于你的设备与系统安全设置。建议不要将设备交给不可信的人使用，并及时更新系统安全补丁。

八、免责声明

本游戏为模拟经营类娱乐产品，所有行情、公司、新闻、收益均为虚构随机生成，不构成任何投资建议，也不代表任何真实市场情况。

九、政策更新

若本政策发生变更，我们会在本页面更新内容并修改上方的生效日期。重大变更时会在应用更新说明中提示。
