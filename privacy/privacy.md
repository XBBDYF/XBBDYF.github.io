## 一、我们收集哪些信息

游戏本体**不收集**任何个人信息，包括但不限于：姓名、手机号、身份证号、邮箱、地理位置、通讯录、相册、麦克风、摄像头数据。

例外只有一个：安卓版本的激励视频广告由第三方广告平台提供，其 SDK 会在播放广告时读取设备信息（设备型号、系统版本、网络状态、应用包名与版本、OAID / Android ID）用于广告投放与反作弊，详见第四节。桌面版与网页版不含任何广告 SDK。

## 二、应用申请的权限及用途

| 权限 | 用途说明 |
| --- | --- |
| 网络访问（INTERNET） | 加载本地页面资源；安卓版本另用于向广告服务器请求广告。游戏存档不会上传。 |
| 查看网络状态（ACCESS_NETWORK_STATE） | 广告 SDK 用于判断网络是否可用，避免断网时反复请求广告。 |
| 安装应用（REQUEST_INSTALL_PACKAGES） | 仅用于广告落地页中「下载安装」类广告的跳转，不会安装任何非你主动点击的应用。 |

本应用不申请位置、通讯录、短信、相机、麦克风、相册、存储、电话状态等敏感权限。

## 三、游戏数据如何保存

1. 游戏存档、成就记录、音效设置保存在你的设备本地（浏览器本地存储或应用私有数据目录）。
2. 这些数据不会上传到任何服务器，也不会与任何第三方共享。
3. 卸载应用或在系统设置中清除应用数据，即会永久删除上述本地数据，我们无法恢复。
4. 单个存档文件大小约 1–2 MB，不包含任何个人身份信息。

## 四、第三方服务

**桌面版 / 网页版**：不接入任何第三方 SDK，不含广告、统计、推送、支付服务。

**安卓版**：接入「TapADN 广告 SDK」（上海艾得蒽数字科技有限公司，TapTap 旗下广告平台），仅用于展示激励视频广告。该 SDK 不会采集你的位置、通讯录、短信、相册、IMEI、已安装应用列表，也不会读取游戏存档内容。

- SDK 隐私政策：https://ssp.dirichlet.cn/docs/agreement/
- SDK 合规说明：https://ssp.dirichlet.cn/docs/compliance/

**个性化广告开关**：首次启动时会询问是否允许个性化推荐；关闭后广告数量不变，但相关度降低。

游戏内的公司、股票、行情、新闻均为随机生成的虚构内容，不对接任何真实交易所或金融数据接口。

## 五、未成年人保护

本应用不主动收集任何用户信息，因此不存在收集未成年人个人信息的情形。若未成年人使用本应用，建议在监护人指导下进行。

## 六、你的权利

1. 你可以在游戏内「重新开始」清除当前存档。
2. 你可以在系统设置中清除应用数据或卸载应用，删除全部本地数据。
3. 你可以拒绝或撤回「个性化广告」授权：首次启动时可直接选择关闭，也可在系统设置中清除应用数据后重新选择。
4. 除广告 SDK 为投放广告所必需的信息外，我们本身不收集你的个人信息。

## 七、数据安全

由于所有数据仅保存在本地设备，数据安全取决于你的设备与系统安全设置。建议不要将设备交给不可信的人使用，并及时更新系统安全补丁。

本游戏为模拟经营类娱乐产品，所有行情、公司、新闻、收益均为虚构随机生成，不构成任何投资建议，也不代表任何真实市场情况。
