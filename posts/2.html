CSS 容器查询实战

XBXBBDYF·2026.06.13·约 1 分钟阅读

告别视口束缚，让组件真正响应其父容器尺寸。

什么是容器查询？#

传统的响应式设计依赖 @media 查询，基于浏览器视口宽度来调整布局。而容器查询允许我们根据某个父元素容器的尺寸来应用样式，让组件更加模块化、可复用。

/* 定义容器 */
.card-container {
  container-type: inline-size;
  container-name: card;
}

/* 当容器宽度 ≥ 400px 时 */
@container card (min-width: 400px) {
  .card {
    display: flex;
    flex-direction: row;
  }
  .card img {
    width: 40%;
  }
}
